# FIAP Tech Challenge - Fase 2

Optamos pelo `desafio 1`, que visa aperfeiçarmos os modelos criados no `Tech Challenge - Fase 1` através do uso de algoritmos genéticos.

## Configuração

1. Clonar este repositório
2. Instalar o gerenciador de pacotes[uv](https://docs.astral.sh/uv/getting-started/installation/)

### Execução

```bash
cd fase_2
uv run streamlit run app.py
```

O comando acima irá instalar as dependências necessárias (se necessário) e iniciar a aplicação.
